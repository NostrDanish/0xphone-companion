# Security Audit — NostrDanish/0xphone-companion — 2026-10-21

## Summary
Re-run of the 2026-10-20 audit (deep pass). FastAPI "secure task gateway" + Kotlin/Compose Android skeleton. No commits since 2026-10-13 (HEAD 9165799). Full re-read of gateway/app.py confirms **PC-01 still stands: all client-facing endpoints — POST /jobs, GET /jobs/{id}, POST /jobs/{id}/cancel, POST /jobs/{id}/approve — have NO authentication.** `/jobs/{id}/approve` is the human-in-the-loop gate that releases internal/confidential jobs to remote workers; anyone with network access can self-approve exfiltration, submit arbitrary jobs, or cancel any job. Escalates to CRITICAL the moment the gateway is reachable beyond loopback. New this pass: Android manifest sets `usesCleartextTraffic="true"` globally, and the debug crash handler is installed unconditionally (not build-gated). No hardcoded secrets found.

Delta vs 2026-10-20: +1 LOW (PC-06), PC-03 evidence extended (manifest cleartext). Findings: 0 CRITICAL / 1 HIGH / 3 MEDIUM / 2 LOW.

## Findings
| ID | Severity | File/Area | Issue | Recommended fix |
|----|----------|-----------|-------|-----------------|
| PC-01 | HIGH (CRITICAL if tunnel-exposed) | gateway/app.py — POST /jobs, GET /jobs/{id}, POST /jobs/{id}/cancel, POST /jobs/{id}/approve | Re-verified 2026-10-21: none of the client/job endpoints require any credential. `/jobs/{id}/approve` moves `awaiting_approval` jobs (internal/confidential data) to `remote_worker` — unauthenticated self-approval = policy bypass. | Add an authenticated "device owner" principal (token or mTLS client cert) for submit/read/cancel/approve; bind approvals to the on-device user. Release-blocker before any tunnel/LAN exposure. |
| PC-02 | MEDIUM | gateway/app.py — GET /jobs/{job_id} | Unauthenticated read returns full job record incl. `result` payload; job_ids (64-bit random) leak via logs/referrers; no defense in depth. | Require auth on reads; redact `result` for non-owner callers. |
| PC-03 | MEDIUM | gateway/app.py — require_admin; android AndroidManifest.xml | Static bearer token compared with `!=` (not constant-time), no rate limiting, no TLS in design; Android manifest sets `usesCleartextTraffic="true"` globally and GatewayClient default is plaintext `http://10.0.2.2:8000/` — normalizes cleartext credentials. | `hmac.compare_digest`; rate limiting; TLS/mTLS (cloudflared + Access) before remote access; restrict cleartext to a debug network-security-config. |
| PC-04 | MEDIUM | requirements.txt | All deps unpinned (`fastapi`, `uvicorn`, `pytest`, `httpx`) — non-reproducible, no supply-chain pinning. (Unchanged.) | Pin versions; lockfile + hashes (pip-tools/uv); add pip-audit to CI. |
| PC-05 | LOW | gateway/db.py, app.py | Worker tokens/claims plaintext in SQLite; `revoke_worker` re-returns the worker token; paid-model route reuses `worker_token` field as admin token (confusable credential channel). | Hash worker tokens at rest; don't echo tokens after creation; separate admin auth field. |
| PC-06 | LOW (NEW) | android CompanionApplication.kt, CrashActivity.kt | Uncaught-exception handler that displays full stack traces is registered unconditionally in `Application.onCreate` (comment says "Remove for release builds" but no build-type gate). Crash traces can contain job metadata; CrashActivity itself is correctly `exported="false"` and local-only (no network exfil). | Gate handler behind `BuildConfig.DEBUG`; strip traces from release builds. |
